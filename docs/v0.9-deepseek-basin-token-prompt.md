## 0. 视频简介解析（已抓取 BV1gVHA6mEbS）

视频简介给出的原始设定：

- 初始武器：**铁盆**
- 固有天赋：**Token**
- 铁盆：
  - **蓄力**：按得越久，伤害越高、范围越大、音效越响
  - **短按**：小范围挥击；连续 3 下没打到人 ⇒ 触发【要饭】
  - **要饭**：对周围敌人做一次要饭判定，有概率朝你投喂【大白饭】
  - 被动：在副手时，铁盆会自动戴在头上，并增加护盾值
- 新技能：**鲸群集结** —— 召唤一只小肥鱼代替你玩游戏：替你打、替你搬、替你干活，**没有数量上限**。
- 天赋 Token：
  - 大肥鱼/小肥鱼做的每件事都要花 Token（攻击、搬运、瞬移……）
  - Token 花光 ⇒ 当场躺下睡觉，Token 回来再自己爬起来
  - 获取：余额页充值 / 要饭收到的大白饭换 Token

本作的落地映射（已按用户明确要求调整）：

| 原作 | 本作 |
| --- | --- |
| 铁盆是初始武器 | **副武器 Q = 铁盆近战**，主武器保留饭盆/大白饭 |
| 所有行动耗 Token | **移动不耗 Token**；大白饭、蓄力铁盆、召唤小肥鱼耗 Token |
| Token 花光睡觉 | 不做强制倒地（会毁节奏）；Token 不足时禁止大白饭/召唤，铁盆短挥仍可用 |
| 鲸群无上限 | 不设硬上限，只受 Token 与性能保护（场景内最多 8 只） |

## 1. 六个问题的根因与方案

### #1 开局技能/任务介绍时游戏没有暂停

根因有两层：

1. 介绍对话框本身会 `get_tree().paused = true`，但 `main.gd` 的 ESC 暂停监听在暂停状态下仍可能抢先打开暂停菜单；关闭暂停菜单时会把 `paused` 置回 false，于是介绍还在、怪却开始动。
2. 首波敌人在 `_start_room()` 里就已经生成，介绍期间即使逻辑暂停，玩家心理上仍会觉得“怪已经在场”。

修复：

- `main.gd`：`get_tree().paused` 为真时不再打开暂停菜单（对话/登场期间 ESC 只给对话框用）。
- `game.gd`：首房间若会播开场介绍，则 **介绍播完才生成第一波敌人**（`_start_room(index, defer_wave = true)`）。
- 对话框顶部标签改为 `PAUSED // DIALOGUE`，明确“已暂停”。

### #2 手持武器割裂、黑边、GPT 法杖太小

根因：

- 现有武器贴图是 32×32 三帧，角色是 64×64；武器只有角色一半高，像“手里捏了个挂件”。
- 贴图自带 2px 纯黑描边，在 640×360 放大后黑边非常重。
- 武器中心直接压在手部坐标上，没有手臂/袖口连接，视觉上“浮”在角色旁边。
- GPT 法杖头只有 8×8 左右，完全没有“世界顶级模型”的压迫感。

修复（代码侧，不等图）：

1. `hand_device.gd` 支持 **程序化武器绘制**（`proc = staff / rice_bowl / book`），使用 1px 深紫/深蓝描边而不是纯黑，颜色直接取自角色现有调色板。
2. 所有武器增加 **袖口/手臂连接块**（角色 accent 色的暗部 + 1px 描边），从身体连到手。
3. GPT 法杖改为 **56px 长杖 + 14×14 云晶杖头 + 悬浮像素光环 + 3 个浮动像素点**；施法时杖头白闪、后坐，弹体从杖头尖端发出。
4. 瞄准向上时武器自动切到角色身后（`z_index = -1`），避免糊脸。
5. 若用户后续提供重绘贴图，只需替换 `set_held` 的贴图路径与 grip 参数，程序化绘制作为永久 fallback。

### #3 主菜单 Enter 语义

- 去掉第一行“ENTER = 开始游戏”的独立快捷键标签，开始键改为 **F**。
- **Enter / 空格 = 下一步 / 确认当前焦点**，不再对应单独功能。
- 菜单底部提示改为：`W/S 选择 · Enter 下一步 · F 开始`。

### #4 关于界面

### #5 大肥鱼/DeepSeek 武器与 Token 体系（最高优先级）

#### 5.1 Token 蓝条

- DeepSeek 专属资源：`token` 0~100，开局 100。
- 移动、翻滚 **不消耗**。
- 消耗：
  - 大白饭（左键）：**7 Token / 发**
  - 铁盆蓄力重击：**6 Token / 次**（短挥免费）
  - 鲸群集结：**20 Token / 只**
- 回复：
  - 每秒自然回复 **6**（受击/施法后 0.5s 内暂停回复）
  - 击杀 +2
  - 大白饭（要饭掉落）+15
- Token 不足：大白饭/召唤拒绝执行并提示“Token 不足 · 用铁盆要饭”；铁盆短挥仍可用，避免死锁。
- HUD：生命格下方新增蓝色分段条 `TOKEN 78/100`，低于 20 时闪烁。

#### 5.2 副武器：铁盆（近战、蓄力）

文件：`scripts/weapons/sub_iron_basin.gd`（替换 `sub_deep_retrieval.gd`）。

- 按住 Q 蓄力 0~1.1s，移动速度降至 75%，角色身上出现蓄力弧。
- 松开挥击：
  - 伤害 `7 + 22 × ratio`
  - 范围 `34 + 34 × ratio`
  - 扇形 130°，带击退、屏幕震动、像素火花；蓄力越满音效越响
- 短按（<0.18s）：小范围挥击，不耗 Token。
- **要饭**：连续 3 次挥击未命中任何敌人 ⇒ 以玩家为中心 110px 做要饭判定：
  - 范围内每个敌人 55% 概率抛出【大白饭】拾取物
  - 大白饭飞向玩家，拾取 +15 Token
  - 提示“要饭成功 · +Token”；无人时提示“周围没人理你”
- 被动：不蓄力时，铁盆缩小戴在头顶（纯视觉，呼应原作）。
- 视觉：蓄力时隐藏主武器，铁盆出现在手前；挥击生成 `basin_swing.gd` 像素扇形残影。

#### 5.3 技能：鲸群集结

文件：`scripts/fx/fish_minion.gd`。

- E 技能消耗 20 Token，召唤 1 只小肥鱼；冷却 2s（受 `skill_cd` 控制）。
- 不设数量上限，仅做 8 只性能保护。
- 小肥鱼行为：
  - 跟随玩家，围绕玩家游动
  - 自动寻找 240px 内最近敌人，发射小气泡（4 伤害，轻微追踪）
  - 14s 后淡出；可帮玩家吸取附近的大白饭
- 视觉：程序化像素小鲸鱼（蓝身、白肚、青眼、1px 深海军蓝描边），2 帧摆尾。

#### 5.4 三名角色的天赋

| 角色 | 天赋 | 实际效果 | HUD |

### #6 Boss 像素化

现状：Boss 登场对话头像是像素图，但战斗内 Boss 用 `draw_circle / draw_arc / draw_line` 画平滑几何体，与敌人（纯矩形像素块）完全两个画风。

修复 `boss.gd`：

- 本体：2px 网格阶梯状晶体轮廓（用 `_px_rects`），1px 深色描边，内部明暗切面 + 8×8 白色核心 + 方形瞳孔。
- 旋转环：改为 2×2 像素块组成的断续环（每 15° 一块），不再使用 `draw_arc`。
- 预警：像素方括号 + 8 个方向闪烁块。
- 冲刺：阶梯状像素线。
- 保留阶段换色、闪烁、glitch 碎片。

## 4. 验收标准

1. 开局介绍出现时敌人数量为 0；介绍结束才刷怪；介绍期间按 ESC 不会解除暂停。
2. GPT 手持法杖长度 ≥ 角色身高 80%，有 1px 紫描边，无粗黑边；施法从杖头出弹。
3. 主菜单第一行不再显示 ENTER；Enter 推进焦点确认，F 开始游戏。
4. 主菜单“关于”能打开独立页面，ESC/返回按钮可回主菜单。
5. DeepSeek：
   - HUD 有蓝色 Token 条；
   - 移动不扣，左键每发扣 7；
   - Q 铁盆短按/蓄力伤害与范围不同；
   - 连续 3 次落空触发要饭并产生大白饭；
   - E 消耗 20 Token 召唤小肥鱼，可多只；
   - 天赋文案在三名角色选择页可见。
6. Boss 战内本体、旋转环、预警全部为像素块，无平滑圆弧。
