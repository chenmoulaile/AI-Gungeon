## 1. 任务 A：鼠标光标消失（最高优先级，先修）

### 根因

`scripts/ui/ba_cursor.gd` 的 `_hide_system_cursor()` 用 **1×1 全透明图** 覆盖所有系统光标形状，
本意是「隐藏系统箭头、只画自绘十字准星」。回归点在于：

- 自绘准星是 `CanvasLayer(200)` 里的 `Node2D`，失败/被遮挡时**没有任何兜底**，系统光标又已被涂成透明 → 完全是“没鼠标”。
- `scripts/systems/input_device.gd:24` 在检测到手柄时把 `Input.mouse_mode` 设为 `HIDDEN`，
  手柄轴漂移（`|value| > 0.25`）就会误判，鼠标再也回不来。

### 方案（不再自绘准星，改用真实像素光标贴图）

新增 `tools/make_cursor.py`（Pillow），生成 4 张 16×16 PNG：

| 文件 | 用途 | 锚点 |
|---|---|---|
| `assets/ui/cursor_arrow.png` | 菜单：像素箭头（白 + 深蓝 1px 描边） | (1,1) |
| `assets/ui/cursor_arrow_hot.png` | 菜单悬停：金色箭头 | (1,1) |
| `assets/ui/cursor_cross.png` | 战斗：十字准星（青）+ 四角括号 | (8,8) |
| `assets/ui/cursor_cross_hot.png` | 战斗命中/悬停：金色准星 | (8,8) |

`ba_cursor.gd` 重写：

- 删除 `_drawer` / `_on_draw` / `_process` 里的 `position` 跟随，改为 `Input.set_custom_mouse_cursor(tex, shape, hotspot)`。
- `_ready`：加载 4 张纹理，`_apply()` 设置所有光标形状为 arrow 版本。
- `set_battle(on)`：切 arrow / cross 组；`_hot` 变化时切 hot 版本。
- `_process` 保留悬停检测（`gui_get_hovered_control` + `ui_hotspot`/`hot` meta），只在状态变化时重设光标，避免每帧重建。
- 新增 `Input.MOUSE_MODE_VISIBLE` 兜底：`set_shown(true/false)` 控制显隐。

`input_device.gd`：**删除** `MOUSE_MODE_HIDDEN` 分支，手柄接入不再隐藏鼠标。

验收：菜单可见像素箭头；悬停按钮变金色；战斗中变准星；插拔手柄不影响鼠标可见性。

## 2. 任务 B：Claude 改回正面朝向

### 根因

`tools/make_pixel_sprites.py` 的 `CHARACTERS["claude"]` 仍指向旧图 `claude_chibi.png`、`view: 1`（侧面），
注释写着“暂时没有正面三视图”。而现在 `assets/reference/claude_chibi_3view_v2.png`
的第 0 格就是完整正面。

### 方案

```python
"claude": {
    "ref": "claude_chibi_3view_v2.png",
    "view": 0,
    ...
}
```

重跑 `python tools/make_pixel_sprites.py`，重新生成：

- `assets/sprites/claude/{idle,walk,attack,roll}.png`（64×64 横排，脚底对齐 y=61）
- `assets/portraits/claude_pixel.png`（96×128）/ `claude_pixel_avatar.png`（32×32）
- `assets/sprites/claude/palette.gpl`

验收：主菜单电梯里的 Claude 与 DeepSeek/GPT 一样正面朝前；眼睛/发色/雏菊发饰仍可辨。

## 3. 任务 C：三把主武器重绘（16 色以内、1px 描边、无抖动噪点）

统一规格：**96×32 三帧横排**（待机 / 开火 / 后坐），朝 +X；24×24 图标；弹丸 16×8 两帧。
画法铁律：**禁止 1px 棋盘抖动**（旧版 `(x*3+y)%7` 是“糊/噪”的来源），只用整块色阶 + 单像素高光。

### 3.1 Claude 主武器 = 大人版立绘手里的书

素材：`assets/reference/claude_adult.png` 中角色抱着的书。

- 造型：竖直厚书，深棕 `#5C3A22` 封面 + 金色 `#FFD166` 包角与书脊 + 封面中央**橙色葵花**（8 瓣，`#FF8A4D` 外瓣 / `#F2B33D` 内瓣）+ 底部两枚金色书扣。
- 待机帧：合书竖立；开火帧：书口微张、页边露出 1px 米白 `#FFF3D6`；后坐帧：整体后移 2px、书页角翘起。
- 图标：24×24 只保留「书 + 葵花 + 包角」三要素。

### 3.2 DeepSeek 主武器 = 蓝瓷鲸纹饭盆（对齐参考图）

- 碗身深蓝 `#2C4A8A`，口沿/碗底金色描线，碗身正中**鲸鱼纹章**（米白 2×3 像素块 + 尾巴 3px）。
- 碗内米饭米白 `#FFF3D6` + **青色 Token 方块**（`#7FE3FF`，1×1/2×2 交替，密度 ≤18 个）。
- 开火帧：碗体上浮 2px、米粒 +2；后坐帧：碗体后移 2px、撒出 2 粒米。

### 3.3 GPT 主武器 = 银饰云端杖（对齐参考图）

- 杖身银灰 `#C9D2E4` + 深灰 1px 描边，中段缠绕卷草纹（金 `#FFD166` 2px 卷）；杖尾紫穗 2 束。
- 杖头银爪（左右各 3 根 1px 爪指）**托住青白云球**（4 块圆角块 + 2px 深蓝眼睛）；云球下挂紫色菱形宝石 2 颗。
- 开火帧：云球放大 1px + 白光十字 2px；后坐帧：整体后移 2px、紫穗甩尾 3px。

## 4. 任务 D：三把专武（同规格 96×32 + 24×24 图标 + 战斗手感不变）

### 4.1 DeepSeek「Harness」→ 外骨骼

- 造型：**背挂式动力外骨骼**，深灰蓝 `#1A2238` 骨架 + 青色 `#7FE3FF` 能量管线 + 肩部 2 个推进喷口。
- 待机：骨架折叠成 L 形挂在持械手；开火：两条机械臂前伸 6px、喷口喷出 2px 青焰；后坐：机械臂回收 2px、管线闪白。
- 图标：24×24 取「折叠骨架 + 青色管线 + 喷口」剪影，读作 `⊐` 形。
- 玩法保持不变（虎鲸虚影冲刺、满 10 token 双击吞噬）。

### 4.2 GPT「Codex」→ 律法典籍

- 造型：**悬浮法典**，米白书页 `#FFF3D6` + 金色符文行（3 行 1px 短横）+ 深蓝书脊；书页两侧各 1 枚金色括号。
- 待机：书页半开；开火：书页张开 + 3 个金色符文点飞出（弹丸用 `proj/codex.png`）；后坐：书页合拢 2px。
- 图标：24×24 只保留「半开书 + 3 行符文 + 金色括号」。
- 玩法保持不变（财富印记两段伤害）。

### 4.3 Claude「Claude Code」→ 终端法典（新增，替换法槌）

- 造型：**深色终端石板**（`#101628` 面板 + `#26304D` 边框 + 青色 `#7FE3FF` 代码行 3 条 + 橙色 `#FF8A4D` 光标块），顶部 1px 金色天线，背面小雏菊。
- 待机：石板竖立；开火：代码行整体上移 1px、光标闪烁两帧；后坐：石板后移 2px。
- 图标：24×24 取「终端窗口 + 橙色光标块」。
- 玩法（新脚本 `scripts/weapons/excl_claude_code.gd`）：
  - 左键发射**代码行**：短条状穿透弹（复用 `proj/page.png` 改为青金色调），命中后按「编译计数」每 3 发追加 1 次 `critical` 判定；
  - 被动：护盾吸收敌弹时，优先把吸收量转成下一次射击的 +1 穿透（最多 3 层）；
  - 解锁条件沿用 Claude 现有 `excl_clean_floor`（无伤过层），
    `resources/characters/claude.tres` 的 `exclusive_name/desc/path` 同步改为 Claude Code；
  - 删除 `scripts/weapons/excl_hammer.gd`、`assets/weapons/excl_hammer.png`、`assets/icons/weapons/excl_hammer.png` 及其 `.import`，`shop.gd` 分支改指向 Claude Code 图标。
